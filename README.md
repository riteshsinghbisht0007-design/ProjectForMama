# SummonMitra - Smart Summon Management Assistant

A web application designed for law enforcement officers to track, schedule, and process judicial warrants, summons, and court appearances.

## Features

- **Officer Command Dashboard**: Real-time summary of active summons, due today items, urgent warrants, and served notices with live clock and telemetry.
- **Monthly Judicial Calendar**: Interactive monthly calendar showing court hearing schedules with day-by-day docket views and quick scheduling.
- **Summons Docket & Search**: Complete summons search by FIR number, subject name, court, and charges with quick status updates and filter chips.
- **Operational Alerts Feed**: Real-time dispatch alerts and judicial court notices categorized by urgency.
- **AI Document & QR Code Scan**: Simulated AI OCR document capture and QR barcode scanner to auto-populate summon details from warrants.
- **Officer Profile & Telemetry**: Manage officer details, department credentials, badge number, and system isolation telemetry.
- **Secure Authentication**: Official sign-in with Google or department credentials.

## Technology Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS with dark tactical theme
- **Icons**: Lucide React
